## 🤔 What's Resonance?

Resonance is a Music Streaming app made with Java and Kotlin, it's meant to be a place where anyone can share their musics and projects!

## ✨ Features

Here, you'll:

- Find other people's musics and projects
  - This also includes archived projects, so you'll be able to hear their musics even when they're not being worked on anymore!
- Find ways to customize your profile
- Find ways to post your own musics and albums
- Be able to create, edit and delete your own playlists
- Be able to create, edit and delete your own albums

## 🔎 How to emulate the app

Simply clone this repository:

```bash
git clone https://github.com/gabrielEFagundes/resonance-frontend
```

Then, execute the app on your favorite emulator, like [Android Studio](https://developer.android.com/studio?hl=pt-br)!

Don't know how to configure the mobile emulator? We'll help!

## 📱 How to configure the mobile emulator

First, add a new mobile emulator on the **Device Manager** tab.

Use the `Pixel 6` phone, it's usually the best one to emulate screen size and API.
